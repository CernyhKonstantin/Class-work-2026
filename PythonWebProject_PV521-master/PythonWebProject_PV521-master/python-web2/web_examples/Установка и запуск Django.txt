Django get started!

0) Проверьте установлен ли у вас pip:
- для этого в PowerShell пропишите следующую команду:
    pip -V
если у вас pip установлен переходите на шаг 1.
Иначе вызовите следующую команду, которая установит pip:
    python -m ensurepip --upgrade
Если pip раннее был установлен его можно и обновить:
    python -m pip install --upgrade pip

1) Первым делом необходимо создать виртуальную среду вашего проекта. При работе с Django использование виртуальной среды 
является примером хорошей практики. 

Виртуальная среда — это изолированная среда, которая содержит определённую версию Python и набор библиотек, необходимых для 
конкретного проекта. Она позволяет избежать конфликтов между библиотеками и их версиями, если вы работаете над несколькими 
проектами.

Зачем нужна виртуальная среда?
Представьте, что вы разрабатываете приложение на Django определённой версии, а затем начинаете новый проект, который требует более 
новой версии Django. Если бы вы устанавливали библиотеки глобально (для всей системы), то обновление Django для нового проекта 
могло бы сломать ваш старый проект, который зависит от старой версии. Виртуальная среда помогает избежать таких конфликтов, так 
как она изолирует зависимости каждого проекта.

2) И так перейдем к созданию среды
- Создаем директорию под наш проект, в котором и будет содержаться наша среда 
- Открываем эту директорию с помощью PowerShell
- Прописываем следующую команду:
python -m venv <venv_name>
- Теперь нам необходимо запустить нашу среду(есть несколько способов это сделать):
!!!Первым делом перейдите в директорию вашего проекта, в которой содержиться директория вашей среды
И так теперь про активацию среды:

-- Windows(Командная строка): <yourVenvName>\Scripts\activate.bat

-- Windows(PowerShell):
!По умолчанию запускать скрипты с помощью PowerShell вы не можете, для этого необходимо прописать политику:
Открываем PowerShell от имени администратора и пишем:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
и далее активируем среду: <yourVenvName>\Scripts\Activate.ps1

-- Linux & MacOS: source <yourVenvName>/bin/activate

Знаком того что вы сделали всё правильно, интерфейс CLI теперь будет выглядить так:
(<yourVenvName>) PS <ProjectPath>

!!!ВСЕ ПОСЛЕДУЮЩИЕ КОМАНДЫ В POWERSHELL БУДУТ ВЫПОЛНЯТЬСЯ ВНУТРИ ВИРТУАЛЬНОЙ СРЕДЫ

! Для деактивации виртаульной среды просто пропишите: deactivate

3) Уже в активированной среде необходимо установить Django:
!Рекомендация: отключите VPN, иначе скачивание не начнется
Установка последней версии:
    python -m pip install django
есть возможность выбрать конкретную версию Django: 
    python -m pip install django~=4.0.0

4) Далее проверяем работу Django
Запускаем Python:
python
>> import django
>> django.get_version() 
# Output: 'maj.min.patch'
>> exit() # close python

5) Создаем первый проект, для этого необходимо использовать django-admin:
django-admin startproject <projectName>

В итоге у вас должно получиться следующая иерархия:
-VenvProject
-- <yourVenvDir>
-- firstProject
--- manage.py 
--- firstProject
---- __init__.py
---- asgi.py
---- settings.py
---- urls.py
---- wsgi.py

6) Проверяем работу, для этого небходимо запустить сервер:
python manage.py runserver
в последствии мы откроем сайт с поздравлениями, и ссылками на документацию Django

7) Проект мы создали, а приложение нет!
для создания приложения используем также CLI:
python manage.py startapp <appName>
в проекте должна добавиться директория с названием которое вы указали и должна содержать следующие файлы:
migrations
- __init__.py
__init__.py
admin.py
apps.py
models.py
tests.py
views.py

8) Приложение необходимо зарегистрировать, для этого:
- откройте файл settings.py
- добавьте в список INSTALLED_APPS ваше приложение:
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    '<yourApp>'
]
